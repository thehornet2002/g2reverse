# g2reverse: Reverse V2Ray/Xray Tunnel via GitHub Actions

ارتباط معکوس مستقیم از GitHub Actions به سمت سیستم کاربر (بدون Codespaces و بدون هیچ سرور واسط).

## معماری
1. **سمت شما (Portal):** کلاینت Xray روی سیستم شما اجرا شده و روی پورتی مثل `8443` آماده دریافت اتصال است.
2. **سمت گیت‌هاب (Bridge):** اکشن گیت‌هاب در داکر اجرا می‌شود و یک ارتباط خروجی به IP عمومی و پورت شما برقرار می‌کند. ترافیک اینترنت آزاد از همین تونل برگشت داده می‌شود.
3. **پورت لوکال کلاینت:** روی سیستم شما یک پورت Socks5 (`127.0.0.1:10808`) و یک پورت HTTP (`127.0.0.1:10809`) باز می‌شود که اینترنت آزاد گیت‌هاب را دارند.

---

## ۱. تنظیم پورت روی مودم (Port Forwarding)
1. وارد پنل مودم شوید (معمولاً `192.168.1.1`).
2. به بخش **Port Forwarding** / **Virtual Server** بروید.
3. پورت دلخواه (مثلاً `8443`) با پروتکل TCP را به IP محلی کامپیوترتان فوروارد کنید.

## ۲. اجرای Xray روی سیستم شما
فایل `client-config.json` را با هسته Xray اجرا کنید:
```bash
xray run -c client-config.json
```
*(اگر پورت متفاوتی روی مودم ست کردید، در `client-config.json` مقدار `portal-in -> port` را با همان پورت یکی کنید).*

## ۳. اجرای GitHub Action
1. ریپازیتوری را در اکانت خود پوش کنید.
2. به تب **Actions** رفته و گردش‌کار **Xray Reverse Bridge** را انتخاب کنید.
3. روی **Run workflow** کلیک کنید:
   - **Your Public IP:** آی‌پی پابلیک اینترنت مخابرات/ثابت خود را وارد کنید.
   - **Your Forwarded Port:** پورتی که روی مودم فوروارد کردید (مثلاً `8443`).
   - دکمه **Run workflow** را بزنید.

## ۴. استفاده
پس از شروع اکشن، در سیستم یا گوشی خود پراکسی را روی:
- **SOCKS5:** `127.0.0.1:10808`
- یا **HTTP:** `127.0.0.1:10809`

تنظیم کنید تا تمام ترافیک از سرور گیت‌هاب رد شود.
